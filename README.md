# Complete AWS DevOps Project

## Project Overview

End-to-end DevOps implementation using:

- GitHub
- GitHub Actions
- Maven
- SonarQube
- Docker
- Amazon ECR
- Kubernetes / Amazon EKS
- Terraform
- Ansible
- Prometheus
- Grafana

## Deployment

1. Clone repository.
2. Configure AWS credentials.
3. Run Terraform.
4. Configure Ansible.
5. Build Maven application.
6. Build Docker image.
7. Push image to ECR.
8. Deploy to EKS.
9. Monitor using Prometheus and Grafana.
